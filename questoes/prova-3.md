### Q21 · resposta-modelo

**(a)** A − λI = [[7 − λ, 2], [2, 4 − λ]]. det = (7 − λ)(4 − λ) − 4 = λ² − 11λ + 24 = 0 → (λ − 8)(λ − 3) = 0 → **λ₁ = 8, λ₂ = 3**.

**(b)** λ = 8: [[−1, 2], [2, −4]] → −x + 2y = 0 → x = 2y → **v₁ = (2, 1)**. λ = 3: [[4, 2], [2, 1]] → 2x + y = 0 → y = −2x → **v₂ = (1, −2)**.

**(c)** P = [[2, 1], [1, −2]]; D = diag(8, 3); det(P) = −5 → P⁻¹ = (1/−5)·[[−2, −1], [−1, 2]] = [[0,4, 0,2], [0,2, −0,4]].

**(d)** D³ = diag(512, 27). P·D³ = [[1024, 27], [512, −54]]. A³ = P·D³·P⁻¹ = **[[415, 194], [194, 124]]**. Conferindo: A² = [[53, 22], [22, 20]]; A²·A = [[53·7 + 22·2, 53·2 + 22·4], [22·7 + 20·2, 22·2 + 20·4]] = [[415, 194], [194, 124]].

**(e)** A direção de v₁ = (2, 1), com λ = 8, carrega mais informação: 8/(8 + 3) ≈ **72,7%** da variância total (8 é 8/3 ≈ 2,7 vezes o autovalor 3). Na prática, manter só essa projeção reduz dimensionalidade perdendo pouca informação.

### Q22 · resposta-modelo

**(a)** Acurácia = (60 + 380)/500 = **0,88**. Precisão = 60/(60 + 40) = **0,60**. Recall = 60/(60 + 20) = **0,75**. Especificidade = 380/(380 + 40) ≈ **0,905**. F1 = 2·0,60·0,75/(0,60 + 0,75) ≈ **0,667**.

**(b)** TPR (recall) = 0,75; FPR = FP/(FP + TN) = 40/420 ≈ **0,095**. Esse é um ponto da ROC. A curva mostra TPR × FPR para todos os limiares; a AUC resume tudo em um número (0,5 = aleatório; 1,0 = separação perfeita). A curva precisa de um **score contínuo** (`predict_proba`, probabilidade da classe positiva); `predict` já aplica um limiar e devolve só a classe.

**(c)** O falso negativo (mau pagador aprovado) é o erro mais grave, então prioriza-se o **recall**: reduz-se o limiar (por exemplo, 0,5 → 0,3), o que diminui os FN, aumenta os FP e portanto **reduz a precisão** (trade-off). Se o pior erro fosse o oposto (recusar um bom cliente e perdê-lo), priorizaria-se a **precisão**, elevando o limiar.

**(d)** Previsão = 0,20 + 0,30 + 0,15 − 0,10 = **0,55**. O SHAP explica **uma previsão individual** (valor base + soma das contribuições = previsão), mostrando por que este cliente foi sinalizado. A importância global só indica o peso médio das variáveis no modelo inteiro.
